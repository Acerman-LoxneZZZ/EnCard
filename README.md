# Wordflow

Telegram Mini App с английскими карточками, личными словарями и прогрессом.
Бот: https://t.me/WordsENRUbot. Адрес:
https://wordflow-telegram.amirykaihan515bsu.chatgpt.site.

Свайпы и перетаскивание отключены. Ответы — кнопками «Знаю», «Не знаю» и
«Трудно». Касание переворачивает карточку, динамик произносит слово.

«Словари» открывает обзор общего словаря и личных подборок с прогрессом.
«Открыть» показывает состав; «Учить», «Продолжить» или «Пройти заново» запускает
занятие. В подробностях слова доступны озвучка, повторение и добавление в
подборки. Режим «Выбрать» позволяет добавить сразу несколько слов в личные словари.

Собственные слова можно исправлять и удалять. Изменение перевода или регистра
сохраняет прогресс; другое английское написание возвращает только это слово
на изучение во всех содержащих его подборках. Удаление требует подтверждения
и убирает слово из всех словарей, сохраняя историю занятий и остальные слова.

Профиль показывает последние семь календарных дней: дни занятий, уникальные
повторённые слова, число ответов и до пяти самых трудных слов. Отмена ответа
убирает его из статистики. История начинается после обновления и хранит до
5000 последних ответов за семь дней. При ограничении размера данных профиль
сообщает, что показана часть истории.

## Профили и данные

Один Telegram-аккаунт соответствует одному профилю. Сервер проверяет подпись
initData публичным ключом Telegram и срок входа (до 24 часов). Имя и аватар
берутся из проверенных данных. Токен бота не используется.

Cloudflare D1 (DB) хранит слова, состав словарей, прогресс и настройки.
Каждый запрос получает владельца из проверенного входа. Запись атомарно
сравнивает ревизию: изменения с другого устройства нельзя перезаписать
без явного выбора пользователя.

На устройстве сохраняется отдельная копия каждого профиля. После успешного
онлайн-запуска приложение может открываться без сети благодаря Service Worker;
изменения синхронизируются при восстановлении подключения. Для первого входа
нужен интернет. При устаревшем входе переоткройте приложение через бота.

Прежние данные браузера не переносятся автоматически. В профиле можно выбрать
«Перенести в профиль». Перед заменой сохраняются обе локальные копии;
предыдущую можно скачать в профиле. Другой Telegram-аккаунт не получает эти
слова автоматически.

«Словари» → «Перенести словари» сохраняет и загружает переносимый JSON-файл
со словами, словарями, прогрессом и настройками. Импорт показывает состав
перед подтверждением замены.

Новые копии имеют версию 2 и включают постоянные ключи слов и историю занятий.
Копии версии 1 принимаются с сохранением прогресса; перед миграцией остаётся
локальная recovery-копия. Старый клиент не может заменить профиль v2 сохранением
v1. Лимит документа — 1 MiB; при необходимости сокращается только история.

Копия рабочей базы для просмотра на компьютере хранится в
[`backups/wordflow.sqlite`](backups/wordflow.sqlite). Это снимок таблицы
`profiles`; условия обновления описаны в [backups/README.md](backups/README.md).

## Разработка

Требуется Node.js >=22.13.0. Интерфейс — index.html, сервер — app/ и server/,
синхронизация — public/profile-*.js, схема — db/schema.ts.

```powershell
npm.cmd ci --prefer-offline --no-audit --no-fund
Copy-Item .dev.vars.example .dev.vars
npm.cmd run dev
```

В .dev.vars укажите TELEGRAM_BOT_ID: числовой ID @WordsENRUbot.
Для опубликованного приложения задайте эту переменную через Sites.
Текущий ID бота: 8693618810. Версия с профилями опубликована через Sites;
подключение DB и таблица profiles проверены на рабочем хостинге.
В токене BotFather вида 123456789:... ID — цифры до двоеточия.
Сам токен нигде не нужен и не должен попадать в репозиторий.

```powershell
node --test scripts/profiles.test.mjs scripts/card-input.test.mjs scripts/word-list.test.mjs scripts/wordflow-model.test.mjs scripts/wordflow-activity.test.mjs scripts/wordflow-mutations.test.mjs scripts/wordflow-recordings.test.mjs
npm.cmd run db:generate
npm.cmd run build
npm.cmd start -- --port 4173
```

Для нового локального D1 примените созданную миграцию:

```powershell
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_giant_mad_thinker.sql
```

Браузерная проверка: node .impeccable/review/profiles-check.cjs (сервер на 4173).
Она имитирует Telegram и облачный API. Криптография и SQL проверяются отдельно
в Node-тестах. Проверка на реальном Telegram требует настроенного ID бота.

Новые библиотечные сценарии: `node .impeccable/review/library-management-check.cjs`
на собранном preview (порт 4173). `APP_OFFLINE=1` включает дополнительную проверку
автономного перезапуска; в PowerShell задайте `$env:APP_OFFLINE='1'` перед запуском.

## Публикация

Site определяется .openai/hosting.json. Доступ и адрес сохраняются.
Для профилей требуется Worker-сборка Vinext с D1, а не только HTML в dist.
Размещайте артефакт и миграции через Sites. Локальная копия источников —
.openai/site-source. Изменения в GitHub не обновляют опубликованное приложение
автоматически. Sites применяет серверные миграции при публикации.
