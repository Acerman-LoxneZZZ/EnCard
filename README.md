# Wordflow

Карточки английских слов. `index.html` работает самостоятельно, а размещённая
HTTPS-версия открывается как Telegram Mini App.

На телефоне отвечайте кнопками «Знаю», «Не знаю» и «Трудно». Свайпы и
перетаскивание карточек отключены. Коснитесь карточки, чтобы перевернуть её,
или нажмите динамик на английской стороне, чтобы прослушать слово.

Проверка управления карточками: `node --test scripts/card-input.test.mjs`.

## Использование

Откройте `index.html` или запустите предпросмотр:

```powershell
node scripts/preview.mjs
```

Бот: https://t.me/WordsENRUbot. Кнопка меню «Карточки» открывает размещённое
приложение: https://wordflow-telegram.amirykaihan515bsu.chatgpt.site.
Идентификатор хостинга находится в `.openai/hosting.json`.
Токен BotFather не включается в исходники или HTML. Для работы карточек после
настройки меню токен и отдельный серверный процесс бота не нужны.

## Перенос своих слов

1. В исходном браузере откройте обновлённый `index.html` по прежнему адресу:
   сохранения привязаны к браузеру и адресу приложения.
2. Откройте «Словари» → «Перенести словари» → «Сохранить копию».
3. В Telegram откройте бота → «Карточки» → «Словари» → «Перенести словари» →
   «Загрузить копию» и выберите сохранённый JSON-файл.
4. Проверьте количество слов и подтвердите замену.

В копию входят собственные слова, состав личных словарей, выбранный словарь,
прогресс и настройки. Загрузка заменяет данные в целевом браузере. Перед заменой
сохраните его копию, если оба набора нужны. При ошибке записи прежние значения
восстанавливаются; предыдущая версия также сохраняется локально под ключом
`wordflow.backup.previous.v1`. Повреждённый файл не применяется.

Добавленные слова и прогресс остаются в памяти конкретного браузера или Telegram
на конкретном устройстве. Автоматической синхронизации между устройствами нет.
Страница содержит 20 встроенных слов; личные сохранения не входят в размещаемый HTML.

## Сборка для размещения

```powershell
node scripts/build.mjs
```

Сборка копирует самостоятельное приложение в `dist/index.html`. Исходники и
артефакт отправляются через поддерживаемый процесс Sites; локальная рабочая
копия для размещения находится в игнорируемой папке `.openai/site-source`.
Изменения HTML сами по себе не обновляют опубликованную версию.
