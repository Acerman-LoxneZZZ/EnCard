# Копия базы Wordflow

`wordflow.sqlite` — копия пользовательской таблицы `profiles` из рабочей
Cloudflare D1, выгруженная 14 октября 2026 года в 23:26 по Москве.

Она содержит Telegram ID, имена и аватары профилей, а также их слова,
словари, прогресс и настройки в колонке `document`.

Откройте файл в программе для SQLite и выберите таблицу `profiles`.
Это снимок данных на момент выгрузки. Изменения в файле не записываются
обратно в рабочую базу. Новые данные в D1 не обновляют файл автоматически.

Файл отслеживается Git и отправляется при коммите и `git push`.
Если репозиторий публичный, копия базы доступна всем посетителям.
